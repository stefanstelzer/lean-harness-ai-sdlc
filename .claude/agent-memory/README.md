# Agent Memory

Durable, project-specific notes the harness's agents accumulate across runs —
lessons learned, recurring pitfalls, and conventions worth remembering.

Entries here are written by the `/lessons-learned` skill at the end of a unit of
work and read back by agents on later runs. Treat the contents as append-mostly
institutional memory: concise, dated, and actionable.

Files are committed so the memory travels with the repository.
